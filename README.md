# Dirt Dash

A retro side-scrolling motocross racer that runs in the browser. It's one HTML file with no build step and no dependencies.

## Play

Open `index.html` in a browser, or play the GitHub Pages version.

| Key | Action |
| --- | --- |
| Z | Throttle |
| X | Turbo (heats the engine; ride over blue arrows to cool it) |
| ↑ / ↓ | Change lane |
| ← / → | Lean back / forward in the air; hold ← on the ground to wheelie over logs |
| Enter | Start |
| P | Pause |
| M | Sound on/off |
| Esc | Menu |

On phones and tablets, on-screen buttons appear below the game.

## Modes

- **A: Solo time trial.** Beat the target times for 1st, 2nd or 3rd place.
- **B: Race 3 rivals.** You finish 1st to 4th by race position, with slower riders on the track to weave through.

## Tracks

There are 15 tracks across five difficulty levels, each with its own look. The jumps include kickers, tables, doubles, triples, step-downs, gap jumps over pits and mega jumps. Best times are saved in your browser.
